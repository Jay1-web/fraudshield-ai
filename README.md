# FraudShield AI

FraudShield AI is an intelligent fraud detection and accountability system for digital transactions.

##  Features
- Real‑time anomaly detection using machine learning
- Transaction risk scoring and alerting
- Integration‑ready REST API
- Dashboard for analytics and audit trails

##  Tech Stack
- Python 3.11 / FastAPI / Scikit‑learn
- PostgreSQL / Redis
- Docker / GitHub Actions

##  Setup
```bash
git clone https://github.com/Jay1-web/fraudshield-ai.git
cd fraudshield-ai
pip install -r requirements.txt
python main.py
